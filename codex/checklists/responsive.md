# Responsive Checklist

- [ ] Mobile First aplicado.
- [ ] Testado mentalmente em 360px/375px.
- [ ] Testado mentalmente em tablet.
- [ ] Testado mentalmente em desktop.
- [ ] Sem overflow horizontal.
- [ ] Header/menu adaptado para mobile.
- [ ] Grid empilha corretamente.
- [ ] Cards ficam legíveis no celular.
- [ ] Tabelas têm estratégia mobile.
- [ ] Imagens são fluidas.
- [ ] Tipografia ajusta por breakpoint.
- [ ] Botões são fáceis de tocar.
- [ ] Inputs são fáceis de usar no celular.
- [ ] Espaçamentos não ficam apertados.
- [ ] Modal/Dialog/Sheet funciona no mobile.
- [ ] Footer fica organizado no mobile.
