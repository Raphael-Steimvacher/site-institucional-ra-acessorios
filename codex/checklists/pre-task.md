# Pre-task Checklist

Antes de implementar:

- [ ] Entendi o objetivo da tarefa.
- [ ] Identifiquei o tipo de projeto/tela.
- [ ] Li os arquivos `.codex/` relevantes.
- [ ] Verifiquei a estrutura existente.
- [ ] Procurei componentes reutilizáveis.
- [ ] Procurei schemas existentes.
- [ ] Procurei services/repositories existentes.
- [ ] Identifiquei impacto em responsividade.
- [ ] Identifiquei se há impacto em SEO.
- [ ] Identifiquei se há impacto em acessibilidade.
- [ ] Identifiquei se há impacto em backend/segurança.
- [ ] Tenho uma estratégia simples antes de codar.
