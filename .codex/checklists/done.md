# Definition of Done

Uma tarefa só está pronta quando:

- [ ] Implementa o requisito pedido.
- [ ] Não quebra padrões existentes.
- [ ] Usa TypeScript sem `any`.
- [ ] Componentes estão pequenos e claros.
- [ ] Regras de negócio estão na camada correta.
- [ ] Formulários têm validação quando necessário.
- [ ] APIs validam inputs quando necessário.
- [ ] Loading/empty/error states foram considerados.
- [ ] Responsividade foi verificada.
- [ ] Acessibilidade básica foi verificada.
- [ ] SEO foi considerado em páginas públicas.
- [ ] Performance foi considerada.
- [ ] Imports não utilizados foram removidos.
- [ ] Código morto foi removido.
- [ ] Lint/typecheck/testes foram executados ou recomendados.
- [ ] A entrega foi explicada com clareza.
