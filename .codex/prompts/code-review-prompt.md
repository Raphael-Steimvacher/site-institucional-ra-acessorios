# Prompt: Code Review

Use este prompt para revisar uma implementação.

```txt
Leia o AGENTS.md e revise as mudanças seguindo .codex/code-review.md.

Quero uma revisão crítica, como um desenvolvedor sênior.

Verifique:
- arquitetura;
- separação de camadas;
- SOLID/Clean Code;
- duplicação;
- tipagem;
- nomes;
- responsividade;
- UI/UX;
- acessibilidade;
- SEO quando for página pública;
- performance;
- segurança quando houver API;
- loading/empty/error states;
- possíveis bugs.

Responda com:
1. problemas encontrados;
2. melhorias recomendadas;
3. pontos positivos;
4. prioridade de cada ajuste;
5. patches sugeridos quando fizer sentido.
```
