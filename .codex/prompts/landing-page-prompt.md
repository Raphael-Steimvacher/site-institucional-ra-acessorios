# Prompt: Landing Page

Use este prompt no Codex quando quiser criar uma landing page.

```txt
Leia o AGENTS.md e os arquivos da pasta .codex, principalmente:
- project-rules.md
- stack.md
- architecture.md
- frontend.md
- design-system.md
- ui-ux.md
- responsiveness.md
- seo-accessibility-performance.md
- landing-page.md
- code-review.md

Quero criar uma landing page moderna, responsiva, rápida e focada em conversão.

Objetivo da página:
[descreva o objetivo]

Público-alvo:
[descreva o público]

Oferta/produto/serviço:
[descreva]

CTA principal:
[ex: Entrar em contato pelo WhatsApp / Pedir orçamento / Agendar]

Referências visuais:
[adicione links, prints, Figma ou descreva o estilo]

Requisitos:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Shadcn UI/Radix UI quando fizer sentido
- Lucide React para ícones
- Framer Motion apenas para animações leves que melhorem UX
- Mobile First obrigatório
- SEO básico configurado
- Acessibilidade básica
- Componentes pequenos e reutilizáveis

Antes de implementar, proponha a estrutura de seções e a organização dos componentes.
Depois implemente seguindo os padrões do projeto.
Ao final, revise usando .codex/code-review.md.
```
