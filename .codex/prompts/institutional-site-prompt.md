# Prompt: Institutional Site

Use este prompt no Codex quando quiser criar um site institucional.

```txt
Leia o AGENTS.md e os arquivos da pasta .codex, principalmente:
- project-rules.md
- stack.md
- architecture.md
- frontend.md
- design-system.md
- ui-ux.md
- responsiveness.md
- seo-accessibility-performance.md
- institutional-site.md
- code-review.md

Quero criar um site institucional moderno, responsivo e profissional.

Tipo de negócio/instituição:
[ex: clínica, barbearia, igreja, restaurante, profissional autônomo, software house]

Objetivo do site:
[ex: gerar contato, apresentar serviços, fortalecer marca, mostrar portfólio]

Páginas/seções desejadas:
[Home, Sobre, Serviços, Galeria, Blog, Contato etc.]

Estilo visual desejado:
[descreva ou envie referências]

Informações importantes:
[nome, slogan, serviços, telefone, WhatsApp, endereço, redes sociais]

Requisitos:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Shadcn UI/Radix UI quando fizer sentido
- Lucide React para ícones
- Mobile First obrigatório
- SEO básico por página
- Acessibilidade básica
- Formulário de contato com validação quando necessário
- Componentização limpa

Antes de implementar, proponha a estrutura do site e dos componentes.
Depois implemente seguindo os padrões do projeto.
Ao final, revise usando .codex/code-review.md.
```
